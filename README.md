# 주간 루틴 트래커 (Weekly Routine Tracker)

주 단위로 루틴을 정하고(예: "주 3회 이상 10km 러닝", "주 5회 이상 5시간 순공") 매일 체크하면
캘린더와 주간 정산 화면에서 목표 달성 여부를 확인할 수 있는 심플한 로컬 웹 앱입니다.

서버 없이 브라우저(로컬 파일)에서 바로 동작하며, 모든 데이터는 브라우저의 `localStorage`에
저장됩니다.

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.

VS Code의 Live Server 같은 확장을 쓰면 더 쾌적하게 쓸 수 있지만 필수는 아닙니다.

```
weekly-routine-tracker/
├── index.html
├── style.css
├── app.js
└── README.md
```

## 주요 기능

- **루틴 관리**: 이름, 주간 목표 횟수, 색상을 지정해 루틴을 추가/수정/삭제
- **날짜별 체크**: 오늘(또는 원하는 날짜)에 어떤 루틴을 수행했는지 체크
- **이번 주 진행 상황**: 루틴별 이번 주 달성 횟수를 진행 바로 표시
- **캘린더 뷰**: 월별 캘린더에서 날짜마다 완료한 루틴을 색상 점으로 표시하고,
  각 주 옆에 그 주의 목표 달성 여부(✓ 이번 주 달성) 배지 표시
- **주간 정산**: 지난 주들을 최신순으로 나열해 루틴별 달성 횟수/목표, 전체 달성 여부 확인
- **백업/복원**: 데이터를 JSON 파일로 내보내기/가져오기 (브라우저 데이터 초기화, 기기 이동 대비)
- **다크 모드**: 우측 상단 토글로 라이트/다크 테마 전환

## 데이터 저장 위치

모든 데이터는 브라우저의 `localStorage`에만 저장됩니다 (서버 전송 없음). 브라우저 데이터를
지우면 기록도 사라지므로, 가끔 "내보내기" 버튼으로 백업해두는 것을 권장합니다.

## 향후 아이디어

- 루틴별 연속 달성 주(streak) 통계
- 월간/연간 요약 리포트
- 모바일 반응형 개선
